Cómo decide el Board

Cada agente devuelve un veredicto estructurado. Solo Security y Cost pueden bloquear; el resto advierte. El Consensus re-propone ante un bloqueo (máx. 2 rondas) y el confidence se calcula del acuerdo del Board y las reglas duras superadas — nunca se le pregunta al modelo. Los costos salen de una tabla curada de precios AWS.
